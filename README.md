# My To-Do List 📝

Hi! First project nako ni sa Python, simple ra kaayo hehe.
Gibuhat nako ni para naa koy malista sa akong mga buhatonon, kay makalimot man ko lol.

## Unsaon pag dagan? (How to run)

1. Install sa Flask (kausa ra ni):
```
pip install -r requirements.txt
```

2. Dagan ang app:
```
python app.py
```

3. Ablihi sa browser: `http://127.0.0.1:5000`

Ayaw kalimot, dapat naka install ug Python daan ha.

## Unsa ni siya?

- Maka add ug bag-ong task (type lang unya pislit Add)
- Pislita ang box para ma check kung nahuman na ✅
- Pislita ang ❌ para ma delete (amping kay dritso mawala, wala pay "are you sure?" haha)
- Makita nimo pila na kabuok nahuman, para ma motivate ka 💪

## Mga files

- `app.py` - mao ni ang main code, naa dri ang tanan logic
- `templates/index.html` - ang itsura sa website
- `static/style.css` - para nindot tan-awon, colors ug design

## Note / sunod buhaton

- Karun kay mawala ang tasks if i-close ang app, kay wala pa koy database. Sunod ako ni butangan ug file or sqlite siguro.
- Basin butangan nako ug edit button puhon.
- If naay error, basin wala ka naka install ug Flask, try lang ug `pip install flask`.

Salamat sa pag tan-aw! 😁
